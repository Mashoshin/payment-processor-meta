# Close: PR-ы влиты → тикет закрыт

Вход: путь к тикету в `tickets/review/`.

## Шаги

1. **Проверь, что все PR влиты**: для каждого URL из секции
   `## Pull Requests` тикета и PR меты —
   `gh pr view <url> --json state,mergedAt`. Есть открытые или закрытые
   без merge — остановись и перечисли, что не влито.
2. **Подтяни мету**: `git checkout main && git pull` (PR меты влит,
   локальный main отстаёт). Удали локальную ветку тикета в мете, если
   осталась.
3. **Подтяни сервисы**: `scripts/bootstrap.sh` (pull main всех сервисов
   в workspace/).
4. **Финальный smoke на влитом main**:
   `scripts/run-all.sh && scripts/smoke.sh; scripts/stop-all.sh`.
   - Зелёный — продолжай.
   - Красный — тикет НЕ закрывать: значит, merge что-то сломал или PR-ы
     влиты не полностью. Зафиксируй в «Журнале» тикета, доложи, остановись.
5. **Уборка**: удали remote-ветки тикета, если GitHub не удалил их при
   merge (`git -C workspace/<svc> push origin --delete <tid>`, то же
   в мете); убедись, что worktrees тикета отсутствуют
   (`git -C workspace/<svc> worktree list`).
6. **Закрой тикет**: допиши в «Журнал» даты создания и merge PR-ов
   и результат финального smoke; перенеси файл из `tickets/review/`
   в `tickets/done/`; закоммить этот перенос прямо в main меты
   (housekeeping-коммит, PR не нужен) и запушь.

## Выход

Резюме: что влито, финальный smoke, тикет закрыт. Если тикет породил
идеи новых планов (из «Журнала» или обсуждений) — перечисли их как
кандидатов для следующего `/grill`.
