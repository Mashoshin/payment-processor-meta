# Integration check

Вход: опционально путь к тикету. Без тикета — проверка main: базовый smoke.

## Шаги

1. Определи, какие рабочие копии проверяем:
   - с тикетом — worktrees `workspace/<service>-<ticket-id>` для затронутых
     сервисов, для остальных — `workspace/<service>` (main);
   - без тикета — все из `workspace/` (main).
2. Останови, что запущено (`scripts/stop-all.sh`), очисти хранилища
   проверяемых копий (`rm -f <dir>/var/storage.json`) — тест идёт с чистого
   состояния.
3. Подними сервисы из нужных директорий (`php -S localhost:<port>
   public/index.php` в фоне, порты — из манифестов). Дождись `GET /health`
   от каждого.
4. Прогони `scripts/smoke.sh`. Затем — критерий приёмки из тикета, шаг
   за шагом, сверяя фактические ответы с ожидаемыми.
5. Погаси сервисы. Результаты — в «Журнал» тикета: каждый шаг,
   ожидалось/получилось, зелёный или красный.

## Ограничения

- Красный тест НЕ чинить молча правкой кода — это возврат
  на `/implement-ticket` с описанием проблемы в журнале.
- Ожидаемые значения не подгонять под фактические.

## Выход

Вердикт green / red с таблицей шагов. При green и `approve` от cross-review —
можно мержить ветки тикета в main сервисов и переносить тикет в `done/`.
