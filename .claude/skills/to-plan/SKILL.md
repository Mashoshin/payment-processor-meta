# Итоги гриля → план

Предусловие: в контексте текущей сессии была гриль-дискуссия
с согласованной сводкой. Не было — откажись и отправь на `/grill`:
план без гриля в этой мете не пишется.

## Шаги

1. Собери из контекста сессии: идею дословно, цель, варианты решения
   с причинами отклонения, выбранный вариант, все развилки с решениями
   пользователя (его формулировки — цитатами), возражения гриля и чем
   закрылись, осознанно принятые риски.
2. Создай `plans/P-NNN-<slug>.md` из `plans/PLAN.template.md`
   (NNN — следующий свободный номер).
3. Секция «Открытые вопросы» обязана быть пустой. Обнаружил нерешённое —
   **не пиши план с дырой**: задай вопрос в чате сейчас и дождись ответа.
4. Покажи пользователю краткую сводку плана (не весь файл) и спроси
   подтверждение. После явного «да» — `status: approved`: утверждение
   состоялось в сессии, промпты зафиксированы журналом `sessions/`.
   Без подтверждения — оставь `status: draft` и скажи, чего не хватает.

## Ограничения

- Ничего не изобретай сверх обсуждённого: в план попадает только то,
  что прозвучало в гриль-сессии. Пробел — это вопрос в чат, а не догадка.
- Контракты, тикеты, код — не трогать. Только файл плана.

## Выход

Файл плана (обычно сразу `approved`) + следующий шаг: `/plan-to-tickets`.
