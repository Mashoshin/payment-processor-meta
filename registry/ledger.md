# ledger

Журнал проводок (двойная запись). Единственный источник правды о движении денег.
Проводки только дописываются; баланс счёта вычисляется из журнала.
Никого не вызывает, ни о ком не знает.

- `POST /entries` принимает массив из 1..2 проводок и пишет его атомарно
  (всё-или-ничего): платёж с комиссией — это два плеча в одном запросе.
- Идемпотентность по `payment_id`: проводки с уже известным `payment_id`
  не дописываются, возвращаются ранее записанные (`200`). Тело повтора
  не сверяется — `payment_id` единственный ключ.
- Хранение: `var/storage.json` (массив проводок).
- Владелец: команда ledger (в демо — агент №2).
